About

I'm a programmer working on systems software and programming languages. I also love cars, music, and astronomy.

I also publish work through Subrange, Intelligent Sandbox, and Ripe.

Projects

Programming languages

Ripe
A systems programming language with a compiler written in OCaml. Supports structs, enums, modules, and pattern matching with QBE and x86 backends.
Ceramic
My continuation of Clay for generic programming. Includes work on compiler diagnostics and C binding generation.
Aurum
A stack based language with an interpreter written in C. Supports loops, macros, and direct memory operations.
Expression
An OCaml interpreter for an esoteric language that uses emoticons as syntax. Supports variables, conditionals, and loops.

Systems and tools

mangoOS
A hobby x64 kernel written in C. Boots with Limine and implements interrupt handling, serial output, and framebuffer text.
fulmen
A small Linux container runtime with a command line interface and desktop UI. Pulls container images and runs commands using Linux namespaces.
lumina.h
A C library for reading and writing PPM images. Supports grayscale conversion and color inversion.
cryptus
A command line file encryption tool written in Rust. Uses AES 256 GCM with a password or key file.
nag
An offline todo tracker with a postfix command language. Stores issues in the project directory with tags, priorities, and dependencies.

Embedded

plftool
A toolkit for inspecting, extracting, and rebuilding Parrot drone firmware. Developed while researching the Airborne Night firmware.
LDR Tracking
A Flask dashboard for light sensor readings from Raspberry Pi Pico W devices. Reads recorded measurements from CSV files and charts them over time.

AI

Echo
A Live2D AI VTuber built from separate services for speech recognition, language generation, memory, voice synthesis, and avatar rendering.
TTS
A local speech synthesis service using Piper and Kokoro. Includes voice profiles, sound effects, and a web interface.
Sniper
A GitHub App that reviews pull requests with language models and posts comments on changed lines. Built with Chang Min Bark and Joshua Lee.
Autovia
A web app for semantic segmentation of road images and video using a model trained on Cityscapes. Built with Santiago Hernandez and Warren Wang.

Applications

Astrocord
A Discord bot written in J with a Python proxy for HTTPS and WebSocket connections.
FindMyAdvisor
A dashboard for finding research advisors by topic. Combines faculty profiles, publications, coauthor networks, and a contact shortlist using MySQL, MongoDB, and Neo4j.
TicketMe
A Phoenix LiveView app for monitoring and controlling Raspberry Pis. Shows device metrics, streams logs, and sends commands over WebSockets.
City Watch
A Flask app for exploring Chicago crime reports and testing dispatch recommendations. Uses AVL trees and a priority queue to organize reports.
